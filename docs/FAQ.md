# CrowForge · Perguntas frequentes

### O computador precisa ficar ligado?
Sim. O bot e o painel funcionam enquanto o processo do CrowForge estiver em execução. O Discord mantém os comandos registrados mesmo com o bot offline.

### Como entro no painel?
Com o bot em execução, use **Abrir painel** no aplicativo Windows. O painel abre diretamente no navegador local. A configuração inicial pede o token do bot do Discord.

### Quais módulos preciso ativar?
Escolha os recursos que seu servidor usa. O instalador indica as intents privilegiadas necessárias para a seleção. Confirme essas opções na aplicação correta do Discord Developer Portal. Ative os módulos no painel do servidor configurado.

### Os alertas exigem outra conta?
Twitch usa um ID e um segredo de cliente. YouTube usa uma chave da Data API. O webhook local recebe mensagens de aplicações no mesmo computador.

### Como preservo minha configuração?
Encerre o bot antes de copiar o arquivo de configuração e a pasta de dados. Guarde a cópia em local privado. Uma instalação Windows pode ter esses arquivos no perfil do usuário.

### Quais condições comerciais se aplicam?
A edição Windows 1.1.0 é entregue como Instalar CrowForge.exe. A licença de uso da versão adquirida é perpétua e a validade técnica é de 12 meses a partir da compra. Consulte Guia do comprador e Licença de uso no menu do corvo, perto do relógio.
