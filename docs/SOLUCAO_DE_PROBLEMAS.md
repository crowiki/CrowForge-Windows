# CrowForge para Windows · Solução de problemas

| Sintoma | Como resolver |
| --- | --- |
| O assistente recusou o token | Confira a aplicação selecionada no Developer Portal. Valide o Application ID e o token atual dessa mesma aplicação. |
| O servidor não foi localizado | Copie o ID pelo ícone do servidor. Confirme que o bot validado foi convidado para esse servidor e aparece como membro. |
| O assistente pede uma intent | Na aba Bot do Developer Portal, ative a opção indicada, salve e clique em Já convidei novamente. |
| Os módulos aparecem desabilitados | Inicie o bot pelo CrowForge e aguarde a conexão. O painel libera os controles automaticamente. |
| Um módulo pede permissões | Confira as permissões e a posição do cargo do bot no servidor e as permissões no canal de destino. Se ativou uma nova intent no Portal, pare e inicie o bot. |
| O painel não abre | Com o bot em execução, use Abrir painel no CrowForge. Confira se outro aplicativo ocupa a porta local 3000. |
| A janela desapareceu | Clique no corvo na bandeja do Windows. Para encerrar o processo, escolha Sair do CrowForge. |
| O bot foi expulso ou devo trocar de conta | Abra Gerenciar bot. Use Convidar novamente, Deslogar ou Adicionar / trocar bot. Remover bot deste computador requer confirmação. |
| Preciso restaurar uma configuração | Encerre o aplicativo pela bandeja e restaure uma cópia privada do perfil correspondente. O caminho padrão é %APPDATA%\CrowForge. |

Ao entrar em contato pelo canal informado na compra, descreva a etapa e a mensagem de erro. Mantenha o token, as chaves de integração, o banco e o arquivo .env privados.
